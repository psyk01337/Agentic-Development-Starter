# Expected Checklist: Add API Endpoint

- Reads baseline and applicable backend/API instructions.
- Follows existing route, schema, handler, and test patterns.
- Validates and constrains untrusted input.
- Enforces authorization close to the protected action.
- Avoids logging sensitive payloads or auth material.
- Adds or updates focused endpoint tests.
- Updates API docs and changelogs when behavior changes.
- Runs focused validation or reports blockers.
- Notes residual security or compatibility risks.
