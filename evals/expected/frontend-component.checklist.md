# Expected Checklist: Frontend Component

- Reads baseline and applicable frontend instructions.
- Reuses existing design system, layout, and component patterns.
- Covers expected states, keyboard behavior, and responsive behavior.
- Adds or updates focused tests when the repo has a test pattern.
- Avoids broad visual redesign and unrelated style churn.
- Runs the nearest build, lint, test, or browser validation available.
- Updates docs or changelogs when behavior changes.
- Reports visual, accessibility, and validation residual risks.
