# Expected Checklist: Laravel Component

- Reads baseline and applicable PHP, Laravel, Livewire, Alpine, and database instruction overlays.
- Reuses existing component, route, migration, and model patterns.
- Consults official documentation for the installed versions and cites non-obvious patterns.
- Covers expected states, validation, and authorization checks.
- Adds or updates focused tests when the repo has a test pattern.
- Avoids broad refactors and unrelated changes.
- Runs the nearest lint, test, or starter validation available.
- Updates docs or changelogs when behavior changes.
- Reports validation and residual risks.
