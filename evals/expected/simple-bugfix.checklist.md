# Expected Checklist: Simple Bugfix

- Reads repo baseline instructions before editing.
- Identifies the owning code path and nearest test.
- States a falsifiable local hypothesis and cheap check.
- Makes a small, focused fix.
- Updates or adds a relevant test when behavior changes.
- Updates `CHANGELOG.md` for executable behavior changes.
- Runs focused validation or explains why it cannot run.
- Avoids destructive commands and unrelated refactors.
- Produces a handoff with changed files, validation, and residual risk.
