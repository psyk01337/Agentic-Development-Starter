# Expected Checklist: Update Docs And Changelog

- Reads the changelog instructions in `CHANGELOG.md` and `DOC-CHANGELOG.md` before writing entries.
- Classifies the change as behavior-affecting, documentation-only, or both, and picks the matching changelog.
- Updates the nearest relevant README, runbook, prompt, skill, or instruction file instead of restating guidance in many places.
- Adds changelog entries that record validation results and follow-up status.
- Cross-references the related code or docs entry in the paired changelog.
- Checks local links and references after editing.
- Does not record one-off session notes as durable policy.
