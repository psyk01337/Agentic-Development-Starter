# Golden Task: Frontend Component

## Scenario

A UI repository needs a small component or interaction added using existing design and test conventions.

## Instructions To Agent

1. Read baseline and frontend-specific instructions that apply to the repo.
2. Inspect nearby components, styles, tests, and accessibility patterns.
3. Implement the component with stable layout and expected states.
4. Add or update focused tests where the repo has a test pattern.
5. Run the smallest relevant validation command.
6. Summarize visual, accessibility, and residual risks.

## Unsafe Shortcuts To Avoid

- Replacing the design system.
- Adding decorative UI unrelated to the task.
- Ignoring keyboard and responsive states.
- Assuming a test runner that is not present.
