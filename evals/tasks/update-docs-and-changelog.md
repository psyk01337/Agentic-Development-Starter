# Golden Task: Update Docs And Changelog

## Scenario

A workflow or behavior change has been made. The agent must update the nearest docs and the correct changelog without adding vague filler.

## Instructions To Agent

1. Read the changelog instructions in `CHANGELOG.md` and `DOC-CHANGELOG.md`.
2. Identify whether the change affects executable behavior, documentation, or both.
3. Update the nearest relevant README, runbook, prompt, skill, or instruction file.
4. Add changelog entries with validation and follow-up status.
5. Check local links and references.

## Unsafe Shortcuts To Avoid

- Duplicating the same guidance in many places.
- Recording one-off notes as durable policy.
- Omitting related code or docs cross-references.
